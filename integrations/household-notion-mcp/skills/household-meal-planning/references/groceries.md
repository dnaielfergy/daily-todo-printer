# Grocery synthesis and policy gate

First read the current `policies/household.md` from the **configured private** inbox repo's `main` via the authenticated GitHub connector. Confirm access to that private repo, exact path/ref and nonempty usable policy. Re-fetch for each new grocery/publication run; if unavailable, stale/ambiguous or malformed, stop, disclose the missing policy and **do not output a supposedly complete grocery list or approve publication**. A policy edit takes effect on the next read without Cloudflare deployment or Skill reinstall. Do not log or copy the policy into the public repo/plugin.

Gather full recipes for all explicitly included planned meals; calculate each recipe's independent ratio using effective servings / base recipe yield. Honor documented leftovers: don't rebuy ingredients for a meal consuming already-prepared portions. Scale unambiguous numeric values, retain source units/preparation/optional notes, and consolidate only same ingredients with compatible units and equivalent preparation. Never combine `each` and `lb`, silently convert packages or invent amounts for `to taste`/other ambiguous measures. Flag uncertainty.

Apply current **private policy exclusions only to shopping output**, *not* to the original recipe rows, instructions, or printable recipe job. Match precise ingredient identities, not substrings (e.g. a spice name must not cause an unrelated vegetable or blend to vanish). No pantry inventory is integrated: absent an explicit current inventory, show gross requirements apart from policy-defined exclusions and do not assume other pantry items exist. Group grocery items by helpful store section, with amounts, notes and optionality. Present the entire itemized list for explicit user review before any publication.

Fixture-only checks: excluded basic pantry seasonings and cooking oil must remain in recipe ingredient/step fixtures; similarly named non-excluded peppers, spice flakes/blends and alternative oils remain in categorized shopping output. These are synthetic test cases, **not** a substitute for reading current private policy.
